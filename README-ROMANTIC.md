# 时光星轨 · 我们的宇宙

> "在时间的无垠里，我们相遇，星辰为证，时光为鉴"

## ✨ 项目简介

这是一个极致浪漫与细节化的3D照片展示系统，将你们的珍贵回忆化作漫天星辰，每一颗星星都是一段美好的故事，每一束光芒都是一次心动的瞬间。

### 🌟 核心特色

- **诗意化界面**：所有文案经过精心雕琢，充满浪漫气息
- **视觉盛宴**：流星、星云、心形粒子、心跳动画等多重特效
- **交互体验**：流畅的3D旋转、缩放，点击照片展开时光胶囊
- **情感设计**：从密码验证到照片展示，每个细节都充满爱意
- **技术美学**：Three.js + 自定义着色器 + 物理动画

## 🎨 浪漫细节一览

### 1. 密码验证 - 爱的第一道门
**"只有懂我们故事的人才能进入哦 💕"**

- **月份选择**：记录你们相遇的月份
- **昵称输入**：专属的爱称
- **心动选择**："你是我的..."（星星/月亮/太阳/宇宙）
- **动画效果**：
  - 爱心浮动动画
  - 成功时的粒子爆炸效果
  - 错误时的温柔抖动提示
  - 渐变背景流动

### 2. 加载界面 - 时光之门
**"正在编织我们的宇宙..."**

- **轨道粒子**：三层轨道旋转，中心粒子发光
- **渐变进度条**：从深空蓝到玫瑰粉的优雅过渡
- **诗意引言**：加载过程中轮换显示浪漫语句
- **星云背景**：实时生成的星云效果

### 3. 主界面 - 星辰大海

#### 标题设计
```
✨ 时光星轨 ✨
"每一颗星辰，都是我们的回忆"
```
- 渐变文字：白→星蓝→薰衣草紫→玫瑰粉→白
- 呼吸光效：模拟心跳的柔和发光
- 浮动动画：上下轻柔飘动

#### 星空背景
- **3000颗星星**：随机分布，带星芒效果
- **实时星云**：5层不同颜色的星云叠加
- **流星系统**：每3秒一颗流星划过
- **十字星芒**：偶尔出现的亮星带十字光芒

#### 照片展示
- **光环系统**：每张照片都有旋转的光环
- **心形纹理**：照片上的心形装饰
- **表情符号**：20种不同的浪漫emoji
- **3D球体分布**：照片均匀分布在球面上

### 4. 控制面板 - 魔法按钮

所有按钮都带有：
- 玻璃拟态效果（backdrop-filter）
- 悬停光效（渐变扫光）
- 点击反馈（缩放动画）

**按钮功能**：

- 📜 **时光卷轴**：显示统计面板
- 🎲 **随机回忆**：随机展示一张照片
- 🎨 **星云变幻**：切换5种浪漫配色
- 💫 **星光闪烁**：开关动态光效
- 💕 **心跳同步**：开启心跳模式
- 📸 **捕捉时光**：上传新照片

### 5. 统计面板 - 时光印记

```

🌟 星辰记忆 53 颗
💕 心动指数 99%
```

- 玻璃质感背景
- 悬停位移效果
- 图标弹跳动画
- 动态数值计算

### 6. 照片查看器 - 时光胶囊

点击照片后进入沉浸式查看：

- **心跳背景**：三层心跳波纹扩散
- **照片浮动**：上下轻柔浮动动画
- **日期显示**：中文长格式日期
- **浪漫描述**：每张照片都有专属文案
- **毛玻璃效果**：背景模糊处理
- **优雅关闭按钮**：旋转动画

### 7. 交互细节

#### 鼠标交互
- **悬停预览**：鼠标靠近照片时显示详情卡片
- **轨迹粒子**：点击时产生10个粒子爆炸
- **平滑旋转**：鼠标移动控制球体旋转

#### 触摸交互
- **手势提示**：首次进入显示诗意提示
- **双指缩放**：支持多点触控
- **流畅动画**：60fps的流畅体验

#### 动画系统
- **缓动函数**：所有动画使用贝塞尔曲线
- **链式动画**：多个动画依次触发
- **物理效果**：模拟真实物理运动

### 8. 氛围模式

#### 心跳模式 💕
- 灯光强度随心跳变化
- 照片大小同步心跳
- 背景心跳波纹
- 浪漫文案提示

#### 星云变幻 🎨
5种预设配色：
1. **深空蓝** - "深邃如你的眼眸"
2. **星云紫** - "梦幻如你的笑容"
3. **极光绿** - "生机如你的陪伴"
4. **玫瑰金** - "温暖如你的拥抱"
5. **晨曦粉** - "温柔如你的细语"

#### 星轨流转 🌙
- 自动缓慢旋转
- 营造时光流逝感
- 可手动干预

### 9. 文案设计

所有文案都经过诗意化处理：

- **按钮文案**："星轨流转"而非"自动旋转"
- **提示文案**："轻触星辰，唤醒回忆"而非"点击照片"
- **加载文案**："正在编织我们的宇宙"而非"加载中"
- **统计文案**："星辰记忆"而非"照片数量"

### 10. 技术浪漫

#### 性能优化
- **WebGL渲染**：GPU加速
- **对象池**：粒子系统复用
- **懒加载**：按需加载资源
- **内存管理**：及时清理无用对象

#### 视觉效果
- **着色器编程**：自定义发光效果
- **混合模式**：Additive Blending
- **后处理**：实时模糊和发光
- **色彩空间**：HSL色彩过渡

## 🛠️ 自定义配置

### 修改纪念日
在 `config.startDate` 中设置：
```javascript
startDate: new Date('2024-01-01') // 你们的纪念日
```

### 修改密码答案
在文件顶部找到：
```javascript
correctMonth: "1",        // 第一次见面的月份
correctNickname: "宝宝",  // 昵称
correctWord: "宇宙"       // 心动答案
```

### 添加真实照片
在 `createPhoto` 函数中，替换canvas绘制为真实图片：
```javascript
const texture = new THREE.TextureLoader().load(`photos/photo${index}.jpg`);
```

### 修改浪漫文案
在 `config.captions` 数组中，为每张照片添加专属故事：
```javascript
"初见时，星辰初绽 ✨",
"你的眼眸，是宇宙最亮的星 👀",
// ...更多故事
```
